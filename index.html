Mouse
Middle drag ........ orbit          Shift+Middle ...... pan
Wheel / Ctrl+Middle  zoom           Alt+Left drag ..... orbit (laptop)
Left click ......... select         Shift+Left ........ add to selection
Right click / Esc .. cancel         Left click / Enter  confirm
Keys
G move · R rotate · S scale · then X / Y / Z to lock an axis
Tab  Object ↔ Pose mode (character) · A select all · Alt+A none
Shift+A add · Shift+D duplicate · X / Delete delete
I insert keyframe · Alt+I delete keyframe · Space play
← → frame · ↑ ↓ jump keys · Shift+← → start / end
Numpad 1 / 3 / 7 front / right / top (Ctrl = opposite) · Numpad 5 persp/ortho
Numpad 0 camera view · Numpad . or F frame selected · Home frame all
Ctrl+Z undo · Ctrl+Shift+Z redo · Ctrl+S save version · N side panel
Touch
1 finger drag orbit · 2 fingers pan + pinch zoom · tap select
Move / Rotate / Scale on the left bar, then drag with 1 finger
